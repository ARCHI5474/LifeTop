# LifeTop
いつものネットをここから。

LifeTopは、ブックマーク機能や天気機能、タイマー/ストップウォッチ機能などを一つにまとめた
PasideaSpaceのWebサービスです。
ブラウザのスタートページにすると便利です。

[LifeTopを開く](https://lifetop.pasidea.space/)

Development: Built with AI-assisted coding

## できること

- ブックマーク、リンク集機能「Quickアクセス」
- タスク管理機能「Quickタスク」
- 簡易メモ機能「Quickメモ」
- タイマー / ストップウォッチ機能「Quickクロック」
- テーマカラーや時計フォント、ユーザー名を設定、カスタマイズ可能「Quickパネル」

## コンセプト
「いつものネットを、ここから」

LifeTopは「多機能であること」ではなく、
日常で必要な機能へすぐアクセスできることを重視しています。

機能を増やしすぎず、
シンプルで使いやすいサービスを目指しています。
また、触感を感じるようなアニメーションやデザインを取り入れ、心地よい体験の提供を目指しています。


## デザイン思想

LifeTopの操作感と視覚表現をもとにした設計思想「[PasideaDesign](PASIDEA_DESIGN.md)」。
日常の操作にやわらかな手応えを与えるための原則と、アニメーションの基準をまとめています。

## 高度な設定と追加ゲーム

Quickパネルは右端から開くドロワーです。最下部の「高度な設定」から時計の背景非表示・秒数表示、検索枠の形状、動きを減らす設定、検索エンジンを変更でき、デフォルトに戻せます。ユーザープロフィールでは名前・アイコン・画像を設定できます。外観はダークモードに統一し、Material 3 Expressiveの色・形状・操作状態を採用しています。設定はブラウザに保存されます。検索エンジンはGoogle、Bing、DuckDuckGo、Yahoo! JAPANに対応します（検索候補の取得元は従来どおりGoogle／Wikipediaです）。

囲碁は9路盤の2人対戦で、中国式面積計算・白コミ6.5目を使用します。死石は終局前に取り切ってください。将棋は同一端末での2人対戦で、成り・持ち駒・王手・禁じ手・千日手を判定します。入玉時の持将棋は双方で相談してください。ヒットアンドブローは重複なしの4桁を10回以内に当てる1人用ゲームです。

## アイコン・天気・ゲーム画面

UIアイコンはGoogle公式Material Symbols Outlinedを同梱しています（使用する96種類、約21KB）。独自SVGは使用していません。出典・ライセンス・取得方法は [icons/material/README.md](icons/material/README.md) に記載しています。ユーザーが設定した画像・サイトのロゴ・盤面の駒はそのまま使用します。

天気はヘッダーから独立した小さいカードに表示します。プロフィール画像とアイコン枠の縦横を固定し、同じ役割の背景色を共通化しています。ゲームは画面の高さに合わせて盤面と操作欄を配置し、ウィンドウ内のスクロールを不要にしています。説明は「遊び方」ボタンで開けます。

## 開発時の動作確認

既存テスト: `node --test tests/*.test.mjs`

公式アイコン・天気カード・ゲーム画面の検証: `node tests/weather-games-layout.cjs`。公式フォントの読込、正方形の表示枠、背景色、チェックマーク非表示、全6ゲームのアイコンと操作欄・10件の履歴がスクロールなしで収まることを確認します。

操作・視認性・開閉の検証: `node tests/workflow-audit.cjs`。検索、ブックマーク登録、入力エラー、IME、フォーカス、AIリセット、実フレーム補間、動きの軽減、文字コントラストと天気データの表示を検証します。

レイアウト検証: `node tests/layout-review.cjs`。320〜1440pxと横向き画面で、長い名前・タスク、各ゲームのはみ出し、パネル開閉による画面幅の変化を確認します。

追加機能のブラウザテスト: `node tests/advanced-browser.cjs`。

ブラウザテスト: Playwrightを利用できる環境で `node tests/browser-smoke.cjs`。
必要に応じて `BROWSER_PATH` にChrome等の実行ファイル、`PLAYWRIGHT_MODULE_PATH` にPlaywrightの `index.js` の絶対パスを指定できます。
外部通信を無効にし、起動、タスクの追加・削除・復元、メモの保存、タイマー、設定、モバイル幅のタブ操作を確認します。
旧ライトモード設定の移行も確認します。追加機能テストではプロフィール画像の保存、リセット、320〜1440px幅でのドロワーと横はみ出しも確認します。
